# AI Usage
I used DeepSeek Opencode during the development of this project, mainly while working on the backend.

I did not use it to build the whole project automatically. I used it as an assistant when I needed help with some implementation tasks, checking Express best approaches or solving issues.

## How I used it
For the backend, I used OpenCode to help with some parts of the implementation, such as:

- creating some initial service/controller structure
- helping with error handling
- debugging some issues
- suggesting improvements to the code
- understanding more the Node JS best practices and workflows

My usual workflow was to first understand what I needed to implement, then use OpenCode when I need assistance. I reviewed the generated code and changed it when needed then testing it before using it in the project.
